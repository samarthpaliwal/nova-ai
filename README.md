# Nova AI

Nova AI is a Python-based artificial intelligence project designed to process user input and execute basic commands. This repository contains the core logic and experimental features for the Nova AI assistant.

## Features
* **Input Processing:** Captures and interprets user text commands.
* **Modular Design:** Structure allows for easy expansion of AI capabilities.
* **Python Architecture:** Built using standard Python libraries for compatibility and performance.

## Getting Started

### Prerequisites
* Python 3.8 or higher
* Git

### Installation
1.  Clone the repository:
    ```bash
    git clone [https://github.com/samarthpaliwal/nova-ai.git](https://github.com/samarthpaliwal/nova-ai.git)
    ```
2.  Navigate to the project directory:
    ```bash
    cd nova-ai
    ```
3.  Run the application:
    ```bash
    python main.py
    ```

## Usage
Run the script in your terminal. Nova AI will prompt you for input. Type your command and press Enter. Type `exit` to close the program.
